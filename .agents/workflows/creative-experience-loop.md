# Creative Experience Loop

Dùng khi task yêu cầu UI premium, landing page, cinematic site, motion, 3D/product showcase.

## Loop

1. **Taste Orientation**
   - Đọc project design-system/taste-profile nếu có.
   - Xác định aesthetic target: luxury, cinematic, minimal, enterprise, playful, etc.
   - Xác định anti-pattern cần tránh.

2. **Scene Planning**
   - Chia trải nghiệm thành scene, không chỉ section.
   - Mỗi scene có một focal point và một cảm xúc chính.

3. **Interaction Planning**
   - Xác định user làm gì: scroll, hover, click, drag, inspect.
   - Mỗi tương tác phải có phản hồi có chủ đích.

4. **Implementation**
   - Code modular.
   - Motion tách khỏi business logic.
   - Không làm nặng performance quá mức.

5. **Creative Review**
   - Có quá nhiều UI không?
   - Có bị template không?
   - Có motion vô nghĩa không?
   - Có focal point rõ không?
   - Có khoảng đen/đứt đoạn scroll không?

6. **Polish**
   - Giảm bớt nếu quá nhiều.
   - Tăng nhịp nếu quá phẳng.
   - Tối ưu responsive và performance.
