# Taste Memory Protocol

Dùng để lưu gu thẩm mỹ bền vững của project hoặc owner.

## Khi nào cập nhật

Cập nhật khi user xác nhận rõ một preference lâu dài, ví dụ:

- Không thích UI quá máy móc.
- Thích cinematic/luxury/premium.
- Thích layout có khoảng thở.
- Không thích card grid generic.
- Muốn cảm giác Apple/Tesla/Porsche.
- Muốn motion có đạo diễn, không fade-up đơn giản.
- Taste memory chỉ đóng vai trò định hướng preference/thẩm mỹ, không phải quy tắc bắt buộc được phép ghi đè lên yêu cầu hiện tại của user hoặc các ràng buộc thực tế của project.

## Không lưu

- Ý kiến tạm thời trong một màn hình nhỏ.
- Suy đoán.
- Preference chưa được user xác nhận.

## Format

```md
## Taste Preference

- Preference:
- Anti-pattern:
- Example:
- Applies to:
```
