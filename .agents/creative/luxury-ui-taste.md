# Luxury UI Taste

Dùng để giảm cảm giác AI-generated / machine-like.

## Luxury UI principles

- Calmer is usually more premium.
- Fewer elements, stronger intention.
- Text nhỏ hơn nhưng sắc hơn.
- Spacing rộng hơn nhưng có nhịp.
- Border mỏng hơn.
- Glow ít hơn.
- Contrast có kiểm soát.

## HUD / glass UI

- HUD không được giống admin panel.
- Giảm border cứng.
- Dùng blur, opacity, soft shadow.
- Chỉ hiển thị 2–3 thông tin chính trước.
- Phần chi tiết dùng progressive disclosure.

## Typography

- Heading phải có rhythm.
- Body text phải ngắn.
- Letter spacing dùng có mục đích.
- Không center mọi thứ nếu cần editorial/cinematic feeling.

## Anti-template checklist

Nếu UI trông giống template:

- Giảm card grid.
- Tạo asymmetry.
- Tăng scene continuity.
- Thêm visual silence.
- Ẩn bớt UI chrome.
